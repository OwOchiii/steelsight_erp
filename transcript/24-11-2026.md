Is there anyway to test the bot webhook

## 10:43 Claude

Yes. Test it in three layers, so a failure tells you which part is broken.

#### 1. Check the token, and what Zalo has registered

This calls Zalo directly; the ERP isn't involved. Put the token in a variable so it doesn't end up typed in the URL:

```bash
read -s ZALO_BOT_TOKEN   # paste the token, press Enter
curl -s "https://bot-api.zaloplatforms.com/bot$ZALO_BOT_TOKEN/getMe"
curl -s "https://bot-api.zaloplatforms.com/bot$ZALO_BOT_TOKEN/getWebhookInfo"
```

- `getMe` should return `"ok": true` with the bot's details. If it doesn't, the token is wrong.
- `getWebhookInfo` should show your `https://<service>.onrender.com/zalo/webhook`. If it's empty, the ERP's registration at start-up didn't happen; check the Render log for "Zalo webhook registration failed".

I'm going on Zalo's docs here, and I'm less sure of `getWebhookInfo` than of `getMe`. If it answers "method not found", skip it.

#### 2. Pretend to be Zalo and call the ERP yourself

This checks the secret, the message format the ERP expects, and the linking. In the ERP, click **Link Zalo** to get a 6-digit code, then:

```bash
read -s SECRET   # your ZALO_WEBHOOK_SECRET
curl -i -X POST "https://<service>.onrender.com/zalo/webhook" \
  -H "Content-Type: application/json" \
  -H "X-Bot-Api-Secret-Token: $SECRET" \
  -d '{"ok":true,"result":{"event_name":"message.text.received",
       "message":{"chat":{"id":"test-chat-1","chat_type":"PRIVATE"},"text":"123456"}}}'
```

Replace `123456` with your code.

| Result | Meaning |
|---|---|
| `200` and `{}`, and the account shows **Linked** after a reload | The ERP side works |
| `401` | The secret doesn't match `ZALO_WEBHOOK_SECRET` |
| `200`, but not linked | The code was wrong or expired. The ERP's reply to `test-chat-1` fails, because that chat doesn't exist, and is logged as "Zalo message to chat test-chat-1 failed" |
| `502` or a long wait | Render was asleep; send it again |

Afterwards, press **Stop Zalo notices**, because the account is now linked to the fake chat `test-chat-1`. Also, after 5 wrong codes from the same chat ID, the ERP ignores that chat for an hour, so change the `id` if you get that.

#### 3. The real thing

Scan the QR, send the code from Zalo, and watch the Render log at the same moment:
- **The bot replies and the account shows Linked:** it works end to end.
- **A request shows up but no reply comes:** the ERP got it, and sending the reply failed. Look for a line like "Zalo message to chat … failed".
- **No request shows up at all, but layer 2 worked:** Zalo isn't calling your webhook. Go back to `getWebhookInfo`.

To test on your own PC instead of Render, run `ngrok http 8080` and use the address it prints as `ZALO_WEBHOOK_URL`. Remember to point the webhook back at Render afterwards.
